# Kepler Exoplanet ML Pipeline

Machine learning workflow to classify NASA Kepler transit signals into confirmed exoplanets/candidates or false positives.

## Directory Structure
- `data/`: Contains raw CSV data files.
- `notebooks/`: Exploratory Data Analysis (EDA) and prototyping.
- `src/`: Production python scripts for pipeline automation.
